# Internal project dossier — ARXIS — Traceable Architecture Documentation Workflow

Status: technical prototype; publication and user-interpretation gates pending.

## Why this project exists

Can requirements, decisions, document versions and artifacts for a sample residential project be traced and checked for completeness?

## Mechanism

Stable IDs and version links form a traceability graph; deterministic classification suggests document types; completeness checks expose missing requirement-to-decision-to-artifact paths.

## Evidence chain

Concept record → source map → pre-test prediction → code → unit and negative tests → deterministic result → evidence hashes → case-study draft.

## Claim boundary

The defensible claim is that a narrow, local prototype was implemented and tested on the disclosed fixture. No production, client or realized-impact claim is made.
