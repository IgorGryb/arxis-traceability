# ARXIS — Traceable Architecture Documentation Workflow

## A bounded prototype with an auditable evidence chain

Can requirements, decisions, document versions and artifacts for a sample residential project be traced and checked for completeness?

The project turns a broad platform concept into one deterministic vertical slice. Stable IDs and version links form a traceability graph; deterministic classification suggests document types; completeness checks expose missing requirement-to-decision-to-artifact paths.

**Evidence available:** source map, pre-test prediction, code, unit and negative tests, machine-readable result and SHA-256 evidence manifest.

**Publication boundary:** private draft. The defensible statement is that the disclosed mechanism was implemented and tested on the disclosed fixture. Metadata demonstrator only. The classifier is rule-based and supports review; it does not replace professional judgment or claim CAD/BIM/GIS integration.
