# ARXIS — Traceable Architecture Documentation Workflow

Private, lightweight evidence repository for a validated portfolio prototype.

## Reproduce

```bash
make setup
make test
make reproduce
make docs
```

The prototype uses synthetic residential project metadata and documents. no client drawings, cad, bim, gis or personal data. Its results are technical evidence, not a claim of production deployment or client impact. Start with `docs/DOSSIER.md` and verify `artifacts/evidence-manifest.json`.
