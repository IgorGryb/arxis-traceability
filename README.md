# ARXIS — Traceable Architecture Documentation Workflow

Private, lightweight evidence repository. The current executable is a narrow technical baseline; the enriched portfolio case remains specified and queued.

## Reproduce

```bash
make setup
make test
make reproduce
make docs
```

The prototype uses synthetic residential project metadata and documents. No client drawings, CAD, BIM, GIS or personal data. Its results are technical evidence, not a claim of production deployment or client impact. Start with `docs/FULL-PROJECT-BLUEPRINT.md`, then `docs/DEVELOPMENT-PATH.md`; use `docs/DOSSIER.md` only as the earlier baseline and verify `artifacts/evidence-manifest.json`.
